# Content Signals declare how this site's content may be used. Syntax and
# vocabulary come from the IETF AI Preferences (aipref) working group draft:
#   https://contentsignals.org/
#   https://datatracker.ietf.org/doc/draft-romm-aipref-contentsignals/
#
#   ai-train  training or fine-tuning AI models
#   search    building a search index — links and short excerpts
#   ai-input  feeding a page to a model for a live answer (RAG, grounding)

# All three are yes. Everything here is open to crawl, index, quote and learn
# from. A link back is appreciated, not required.
#
# Content-Signal repeats in every group deliberately. robots.txt groups do not
# inherit: a crawler that matches its own User-agent line never reads the
# wildcard group, so a signal declared only there would never reach it.
