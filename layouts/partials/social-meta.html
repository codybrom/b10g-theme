{{/* OpenGraph + Twitter card tags. Micro.blog injects none of these itself (verified: zero og:/twitter: tags on a stock build), so links shared to Threads, Mastodon, and Bluesky render with no preview card. Since b10g.xyz's per-post `metas.description`/`metas.image` could not survive the Markdown import — nested front matter breaks Micro.blog's parser — everything here is derived from the post itself, which also means new posts get cards with no extra work. */}} {{ $isPost := or (eq .Type "post") .IsPage }} {{/* Description, from Micro.blog's own fields only: 1. `description` front matter, if ever set 2. `summary` — a real per-post field Micro.blog stores and exposes (edit it in the post editor); empty by default, so setting it there wins automatically 3. the post's own summary, which honors 4. the site description No theme-side lookup table: anything authored lives in Micro.blog, not here. */}} {{ $desc := "" }} {{ with .Description }}{{ $desc = . }}{{ end }} {{ if not $desc }}{{ with .Params.summary }}{{ $desc = . }}{{ end }}{{ end }} {{ if not $desc }}{{ with .Summary }}{{ $desc = . | plainify | htmlUnescape }}{{ end }}{{ end }} {{ if not $desc }}{{ $desc = .Site.Params.description }}{{ end }} {{ $desc = $desc | plainify | htmlUnescape | chomp }} {{ if gt (len $desc) 300 }}{{ $desc = printf "%s…" (substr $desc 0 299) }}{{ end }} {{/* Image: Micro.blog photo param > first image in the body > site avatar. */}} {{ $img := "" }} {{ with .Params.photos }}{{ $img = index . 0 }}{{ end }} {{ if not $img }}{{ with .Params.images }}{{ $img = index . 0 }}{{ end }}{{ end }} {{/* The first in the body, held on to so the alt can be read off the same tag as the src. Matching the tag a second time by its URL does not work: a src is full of regex metacharacters. */}} {{ $firstImg := "" }} {{ with findRE `]+>` .Content 1 }}{{ $firstImg = index . 0 }}{{ end }} {{ if not $img }} {{/* Two-step extraction: Go's `.` does not cross newlines, and Micro.blog/Lume emit tags whose alt text wraps onto its own line, so a single replaceRE over the whole tag silently returns the tag instead of the src. */}} {{ with $firstImg }} {{ with findRE `src="[^"]*"` . 1 }} {{ $img = strings.TrimSuffix `"` (strings.TrimPrefix `src="` (index . 0)) }} {{ end }} {{ end }} {{ end }} {{ if not $img }}{{ $img = .Site.Params.social_image | default "" }}{{ end }} {{/* Alt text, read off the same tag the src came from — only when that is where the card image came from, since a photo param or the site avatar has nothing to do with the body. Left empty, Facebook's debugger reports og:image:alt as missing and a screen reader announcing a shared link has nothing to say about the picture. */}} {{ $imgAlt := "" }} {{ with $firstImg }} {{ if strings.Contains . $img }} {{ with findRE `alt="[^"]*"` . 1 }} {{ $imgAlt = strings.TrimSuffix `"` (strings.TrimPrefix `alt="` (index . 0)) | htmlUnescape }} {{ end }} {{ end }} {{ end }} {{/* Threads and Facebook show the title and little else, and "b10g.xyz" there said nothing about the post. The description still carries the full text for anywhere that shows both. */}} {{ $title := partial "post-label.html" . }} {{ if not $title }}{{ $title = .Site.Title }}{{ end }} {{ with $desc }}{{ end }} {{ with $img }}{{ end }} {{ with $imgAlt }}{{ end }} {{ if and $isPost (not .Date.IsZero) }} {{ end }} {{ with $desc }}{{ end }} {{ with $img }}{{ end }} {{ with $imgAlt }}{{ end }} {{ with $desc }}{{ end }}
